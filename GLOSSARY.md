# Pocket — Licensing

How people get the right to use Pocket after the free trial, and how paid
features are separated from the ones included in a one-time purchase.

## Language

**License**:
A person's permanent, one-time-paid right to use Pocket and every feature that is not a Subscription feature.
_Avoid_: Lifetime plan, pro version, purchase

**License key**:
The code a buyer receives after paying, which proves they hold a License.
_Avoid_: Serial, code, token

**Trial**:
A short period after first launch during which Pocket works fully without a License.
_Avoid_: Demo, free version

**Activation**:
The link between one License and one Mac; a License allows a limited number of Activations.
_Avoid_: Seat, device slot, install

**Subscription**:
A future, separately paid, recurring right to use Subscription features; it does not replace the License.
_Avoid_: Pro plan, premium

**Subscription feature**:
A feature that needs an active Subscription even when the person holds a License.
_Avoid_: Premium feature, paid feature
